2. Lokale Speicherung im Browser (localStorage)

GZ-AI. FLOW Board speichert bestimmte Einstellungen im sogenannten localStorage Ihres Browsers. Das ist ein Speicherbereich auf Ihrem eigenen Gerät. Gespeichert werden:

  • Ihr aktivierter Freischaltcode,
  • der zuletzt bearbeitete Board-Stand (automatische Zwischenspeicherung),
  • Anzeige-Einstellungen wie Hintergrundfarbe und Raster.

Diese Daten verlassen Ihr Gerät nicht. Sie werden nicht an uns oder an Dritte übertragen. Sie können sie jederzeit selbst löschen, indem Sie die Browserdaten dieser Seite entfernen.

3. Keine Cookies, kein Tracking

GZ-AI. FLOW Board setzt keine Tracking-Cookies, nutzt keine Analyse-Werkzeuge (z. B. Google Analytics) und erstellt keine Nutzerprofile.

4. Externe Inhalte: nur beim PDF-Import

EINZIGE AUSNAHME VON „OFFLINE"

Die Anwendung funktioniert vollständig offline. Einzige Ausnahme: Beim Import einer PDF-Datei wird einmalig die Bibliothek pdf.js von einem Mozilla-CDN nachgeladen. Dabei wird die IP-Adresse Ihres Geräts an Mozilla übertragen. Diese Funktion wird nur aktiv, wenn Sie selbst eine PDF-Datei importieren.

Alle Schriften, Symbole und sonstigen Bestandteile der Anwendung sind direkt in der Datei enthalten und werden nicht von externen Servern nachgeladen.

5. Live-Sharing (lokaler Server)

Die Funktion "Live teilen" startet auf Wunsch einen lokalen Server auf Ihrem eigenen Rechner (per start.bat). Der aktuelle Bildschirminhalt des Whiteboards wird dabei ausschließlich innerhalb Ihres lokalen Netzwerks (z. B. WLAN im Klassenzimmer) an Geräte übertragen, die den angezeigten QR-Code scannen. Es findet keine Übertragung an einen Server von uns oder an das Internet statt.

6. Aufnahmen (Video/Audio-Export)

Aufgezeichnete Videos, Bilder und Audiospuren werden ausschließlich lokal auf Ihrem Gerät erzeugt und gespeichert (bzw. über den nativen Speichern-Dialog Ihres Browsers). Eine Übertragung an uns findet nicht statt.
