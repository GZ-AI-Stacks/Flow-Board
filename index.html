FAQ

Häufige Fragen

Funktioniert FLOW Board ohne Internet?+
Ja, vollständig offline. Einzige Ausnahme: Der PDF-Import lädt die Bibliothek pdf.js einmalig von Mozilla CDN — das ist optional und nur beim ersten PDF-Import nötig.
Auf welchen Geräten läuft FLOW Board?+
Windows, macOS, Linux, iPad, Android — überall wo Chrome, Edge, Firefox oder Safari ab Version 90 verfügbar ist. Empfohlen: Desktop mit Chrome oder Edge für die beste Stift-Erfahrung.
Brauche ich eine Installation?+
Nein. Einfach die HTML-Datei per Doppelklick im Browser öffnen. Für Mikrofon-Aufnahme und Live-Sharing: die mitgelieferte start.bat ausführen — startet einen lokalen Server auf Port 8080.
Was bekomme ich nach dem Kauf?+
Sofort nach der Zahlung erhältst du eine E-Mail von Digistore24 mit Download-Link und Freischaltcode. Der Code wird einmalig in der App eingegeben und ist danach jederzeit im Browser verfügbar.
Was ist der Unterschied zur Demo?+
Die Demo hat alle 14 Werkzeuge und kein Zeitlimit — einzige Einschränkung: Exporte (PNG, PDF, Video, GIF) tragen ein Wasserzeichen. Der Freischaltcode der Vollversion entfernt das Wasserzeichen und aktiviert den Update-Anspruch. Du kannst die Demo ausgiebig testen, bevor du kaufst.
